# 参考图与生成任务（0.5.0 测试版）

## 角色参考图

角色编辑页使用缩略图勾选公开图片，支持搜索、分页、放大、移除与排序。拖动已选图片可改变顺序，也可以用左移、右移按钮完成相同操作。最多 8 张；第一张作为角色卡片封面。翻页和搜索不清空当前选择，保存失败时保留表单。

所有预览请求均检查公开范围和图库路径。参考图后来被删除或改为非公开时，预览显示不可用；保存时仍会由后端校验，不会因为前端缓存而扩大图片范围。

## 统一任务卡

总览和角色页显示近期任务，导航新增“生成任务”；创作台的任务页也使用同一套卡片。它汇总聊天、指令、创作台及插件产生的历史记录，包括生成失败的任务。

任务卡按实际信息显示排队、生成、角色核对与交付；没有虚构百分比。每 5 秒刷新，页面不可见时暂停。筛选条件、已展开核对详情和操作焦点在刷新时保留。预览采用小图，点击才读取完整结果。

形象核对不通过会显示具体差异，并提供标准参考与生成结果对照。核对结果未知、核对关闭、任务成功生成和图片实际交付是不同状态。历史记录缺少交付证据时显示“交付未记录”，不会声称已经发送。

## 恢复操作

- **生成失败**：重试需要在弹窗中确认，会产生一次新的生成调用；原任务保留，并关联恢复任务。可复用的参数和完整参考图必须仍有效；模型或参数需要回退、参考图缺失时转到创作台调整，不偷偷改参数。
- **角色任务重试**：新任务保存角色外观、画风、参考图顺序和提交提示词快照，重试使用该快照。旧任务没有完整快照时不会自动猜测，界面提供重新创作入口。
- **已有图片交付失败或未确认**：仅发送已归档图片到任务的原会话。弹窗显示目标会话摘要，后端不接受自定义目的地，不会调用生图模型。没有会话来源的创作台任务不能通过该入口发到任意会话。
- **重试结果**：先保存到工坊并保留原会话归属，不自动发消息；生成完成后可明确选择发送到原会话。
- **重复点击或网络重试**：同一操作标识返回同一结果，服务端串行核对任务状态。结果未确认时停止自动重复提交；平台发送结果未知时再次发送可能重复，界面会提示核对原会话。
- **部分生成或结果已清理**：保留已有记录和图片，不自动重画全部内容。到创作台确认参数后按需补画。

恢复接口和跨会话任务列表沿用 Dashboard 管理员鉴权，不开放给普通插件 API Key。新增 `media_tasks.sqlite3` 保存角色快照、阶段与幂等操作结果，保留期限为 90 天；它不替代原生成历史。任务展示数据写入失败不会阻断已有图片的正常生成和交付。

本轮使用模拟供应商和隔离平台发送器验证恢复流程，不向 QQ 发送测试消息。浏览器桌面访问不可用，前端证据为 DOM 交互测试、构建检查与线上静态资源/接口检查，未完成真实浏览器视觉验收。
