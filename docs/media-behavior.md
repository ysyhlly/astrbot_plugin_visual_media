# 表达偏好、去重与角色核对（0.4.0 测试版）

- 自然聊天中的明确指令可保存偏好，例如“以后少发表情”“不要再发表情包了”“多发点表情吧”“我喜欢水彩画风”“这张别再发了”“恢复默认媒体偏好”。按完整 UMO 和成员分别保存；引用、假设和不明确的表达不会自动写入。没有成员身份时不写入群默认设置。
- “我喜欢这个画风”仅在当前会话最近的角色创作有可追溯画风时保存，否则不猜测。当前明确生图要求优先于保存的画风。
- 对最近 12 次、30 分钟内确认发送的同内容图片去重，改名仍算同一张。图像近似且配字相同的候选降序，不直接屏蔽。明确“再发刚才的表情”可重复；普通“来个表情”不会绕过去重。成员禁止的图片仍不发送。
- “少用表情”将主动表情间隔至少拉到 3 分钟；明确要表情时可忽略该间隔。原平台权限、Chat Dynamics 参与与停止规则仍生效。并发同图发送保留 60 秒临时发送权，只有确认发送后才写近期记录。
- 控制台新增“表达与记录”：偏好可恢复默认；按类型和匿名会话筛选选择、过滤、提交、生成、角色核对及真实交付回执。仅有 selected/submitted/generated 不能说明已发送。
- 角色创作完成后，最多取 2 张标准参考图和 2 张生成图调用已配置视觉模型核对，60 秒默认超时。结果为 pass/mismatch/unknown；缺少参考、服务异常或部分未检查均不宣称完全通过。发现差异或无法确认时给出说明，不自动循环重画。普通未绑定角色的生图不会冒充经过角色核对。
- 新数据仅写入插件目录下 `media_behavior.sqlite3`。决策不保存聊天原文，最多 5,000 条、30 天；近期图片记录最多 5,000 条、1 天。偏好长期保留，可重置。会话及成员以哈希标识显示；此标识用于隔离而非授权，后台接口沿用管理员鉴权。
- 角色检查属于辅助模型判断，不能保证原作一致。生成后检查保留原图，不把不通过的图删除；不会自动纳入角色标准参考。

上述时间和条数为兼容默认值，0.4.0 可在插件配置的“媒体行为与角色核对”中调整。独立关闭日志不关闭去重或偏好。
